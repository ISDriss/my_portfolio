# Ilian Sebti – Portfolio

Static Next.js site showcasing my project work, skills, and contact details.  
Live demo: **https://ilian-sebti-portfolio.vercel.app**
Three.js scene attempt (WIP): **https://ilian-sebti-portfolio.vercel.app/threepage**

## Stack
- Next.js 15 + App Router
- Tailwind CSS for styling
- GitHub Pages for hosting (via `next export`)

## Development
```bash
npm install
npm run dev
```
